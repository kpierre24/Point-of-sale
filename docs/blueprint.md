# **App Name**: Simple Sales Tracker

## Core Features:

- Simple Form: A simple form to record products that were sold.
- History: Record the history of the products sold.
- Calculation: Calculate totals, subtotals and taxes.
- Suggestions: The app uses a tool to suggest the product name, price or other information, using an AI model that has been trained on the user's own sales history.

## Style Guidelines:

- Primary color: Light blue (#E0F7FA) for a calm and professional feel.
- Secondary color: Light gray (#F5F5F5) for backgrounds and neutral elements.
- Accent: Green (#4CAF50) for buttons and active states to indicate success and positive actions.
- Clean, sans-serif fonts for readability and a modern look.
- Use simple, consistent icons from a library like FontAwesome or Material Icons to represent actions and categories.
- Clean and structured layout using grids and cards for easy navigation and data presentation.
